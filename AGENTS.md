# Notes for agents

## Run

```bash
npm install
npm run data
npm run dev
```

`npm run data` rewrites `lib/mock/data/seed.json`. Commit that file when the generator changes. The app reads the file, it does not regenerate on boot.

Other commands: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run check:words`, `npm run test:e2e`.

## Git

- Commit as `Denys Sergushkin <sergushkincom@users.noreply.github.com>`.
- Messages are short and plain. No trailers, no "Generated by" lines.
- Do not rebase or force-push.
- One pull request per task. Do not merge it yourself.

## Data rules

- Every supplier, person, address, email and bank in the product is fictional.
- Do not add real company names, real staff names, real emails, real phone numbers or real street addresses.
- The banned-word check reads `.github/banned-words.txt` and fails the build on a case-insensitive match. The list file is the only place those terms may appear. Do not copy the terms into source, tests, docs or commit messages. Tests that need a planted hit must build the string at runtime.
- The generator checks the same list. If you add a term, regenerate the seed and make sure the names still pass.

## Tests

- Assert behaviour with roles and `data-testid`, not exact UI copy. Copy lives in `lib/i18n.ts` and changes with the language toggle.
- Unit tests cover review decisions, scenario math, suggestions, coverage and the generator. Keep them there when you change those rules.

## Where things live

- Visual tokens: `app/globals.css`. Light theme only. Body `#EEF1F8`, sidebar `#E8ECF5`, primary `#3069E6`. Do not add a second brand colour or a dark theme.
- Review rules: `lib/review.ts`. Sensitive price threshold: `PRICE_THRESHOLD_CENTS` in `lib/fields.ts`.
- Seed and campaigns: `lib/mock/generate.ts`.
- Demo state: `lib/store.ts`. "Reset demo" restores the seed.

## Extending

A new screen should use the shell, the tokens, labelled status pills, and seeded data. A new field needs a history entry, a source, and a pass through review before it changes the current value. Do not write a supplier answer straight onto the record.
